# **App Name**: Adegga

## Core Features:

- Wine Catalog: Display a catalog of available wines.
- Order Input: Accept customer orders using a clean, easy to use interface.
- Total calculation: Calculate total due amount.
- Receipt generation: Generate an order invoice or receipt.
- Wine AI tool: Wine recommendation tool. Provide wine recommendations based on customer taste preferences.

## Style Guidelines:

- Primary color: Deep wine red (#800020) to evoke sophistication and the essence of wine.
- Background color: Light beige (#F5F5DC) to provide a neutral and elegant backdrop.
- Accent color: Golden yellow (#FFD700) for highlighting interactive elements.
- Body font: 'Alegreya', a humanist serif with an elegant and intellectual feel; appropriate for the wine descriptions, etc.
- Headline font: 'Belleza', a humanist sans-serif which complements the serif 'Alegreya', for a modern, art-centric feel.
- Use wine-related icons such as grapes, wine glasses, bottles, and cheese to visually enhance the user interface.
- Design the layout to showcase wines with high-quality images and clear, concise descriptions.
